# Comparison of EAP Methods

| Feature                                     | EAP-MD5                          | LEAP                        | EAP-TLS                       | EAP-FAST                            | EAP-TTLS                             | PEAPv0  <br>(EAP-MSCHAPv2)           | PEAPv0  <br>(EAP-TLS)     | PEAPv1  <br>(EAP-GTC)                |
| ------------------------------------------- | -------------------------------- | --------------------------- | ----------------------------- | ----------------------------------- | ------------------------------------ | ------------------------------------ | ------------------------- | ------------------------------------ |
| **Server Certificate**                      | No                               | No                          | Yes                           | Optional  <br>(can use PAC instead) | Yes                                  | Yes                                  | Yes                       | Yes                                  |
| **Client Certificate**                      | No                               | No                          | Yes (also supports smartcard) | No                                  | Optional                             | No                                   | Yes                       | Optional                             |
| **Supported Client Authentication**         | MD5 hash  <br>challenge response | MSCHAPv2 challenge/response | Via Certif./Smartcard         | MSCHAPv2, GTC                       | PAP, CHAP, MSCHAPv2, GTC, Certif.    | MSCHAPv2                             | Certif                    | GTC                                  |
| **Mutual Authentication**                   | No                               | Yes                         | Yes                           | Yes                                 | Yes                                  | Yes                                  | Yes                       | Yes                                  |
| **User Identity Protection**                | No                               | No                          | Yes  <br>(anonymous)          | Yes  <br>(bogus username)           | Yes  <br>(TLS encryption)            | Yes  <br>(TLS encryption)            | Yes  <br>(TLS encryption) | Yes  <br>(TLS encryption)            |
| **Client Auth in cleartext**                | Yes (sniffing possible)          | Yes (sniffing possible)     | No                            | No                                  | No                                   | No                                   | No                        | No                                   |
| **Client Auth Handhshake offline cracking** | Tool eapmd5pass                  | Tool Asleap                 | No                            | Tool Asleap (for MSCHAPv2)          | Tool Asleap (for MSCHAPv2)           | Tool Asleap                          | No                        | Cleartext (inside TLS tunnel)        |
